# User Research

## Project
Smart LMS Mobile Application

## Overview
This folder contains the user research conducted for the Smart LMS Mobile Application project.

The purpose of the research was to understand students' experiences with the current Learning Management System (L.M.S), identify challenges they face, determine the features they use most, and gather suggestions for improving the (L.M.S ) mobile experience.

## Research Method
A questionnaire was used to collect information from university students.

The questionnaire contained both closed-ended and open-ended questions covering:
- Year of study
- Frequency of (L.M.S) usage
- Device used to access the (L.M.S)
- Challenges experienced when using the current (L.M.S)
- Most frequently used (L.M.S) features
- Suggested improvements for the (L.M.S) mobile application

## Participants
A total of **5 students** participated in the user research.

## Research Deliverables

The following files are included in this folder:

### 1. User Research Questionnaire
The questionnaire used to collect information from the participants.

### 2. Completed Questionnaires
A PDF containing the responses collected from the five participants.

### 3. User Research Findings
A summary and analysis of the information collected from the participants.

## Key Areas Investigated
The research focused on:
- (LMS) usage patterns
- Devices used to access the (L.M.S)
- Usability challenges
- Frequently used (L.M.S)features
- User needs and expectations
- Suggested improvements for the proposed mobile application

## Conclusion
The research findings provide useful information about students' experiences and needs when using an (LMS). The findings will be used by the project team to guide the design of the SmartLMS mobile application and help ensure that the proposed system addresses users' needs.
